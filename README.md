### 1. RecruitCopilot — AI-Powered Recruitment Assistant

An AI-powered recruitment application designed to help recruiters analyze resumes, evaluate candidate-job matches, and prepare interview questions.

<p>
  <a href="https://recruit-copilot.vercel.app/"><img src="https://img.shields.io/badge/Live%20Demo-Visit%20App-16A34A?style=for-the-badge&logo=vercel&logoColor=white" alt="RecruitCopilot Live Demo" /></a>

**Key features**
- 📄 Extracts candidate information from PDF resumes.
- 🎯 Scores candidate-job matches to support initial screening.
- 💬 Provides a conversational, RAG-style recruitment copilot using candidate context.
- 📝 Generates AI-assisted interview questions.
- 🔗 Integrates the Google Gemini API for AI-powered functionality.

**Tech stack:** HTML, CSS, JavaScript, Node.js, Express.js, MongoDB Atlas, Google Gemini API, `pdf-parse`
